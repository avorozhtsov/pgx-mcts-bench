# Focused successor program after Q254/Q154

Status: `QUEUED` behind the active Q254 and Q154 terminal gates.

This document records the authorized successor to the historical six-lineage
Q304 plan. The old Q304 bank remains immutable evidence, but it is not an
authorized training program and must not be launched.

## Why the cohort is narrowed

The frozen exact-common Fast evidence identifies `q-grown-strand-graph-12` and
`q-grown-raster-axial-12` as the strongest complementary architectural bases.
Continuing near-duplicate weak lines consumes CPU without testing a useful new
hypothesis. The successor therefore spends compute on controlled forks of the
best global model, one strong local raster control, and one genuinely diverse
Slow model chosen only after its exact-common terminal audit.

The focused cohort contains five lines:

1. a pure-RL `q-grown-strand-graph-12` descendant as a seed-matched control;
2. an otherwise identical descendant receiving replay-validated, set-valued
   NodeDB proof supervision before RL continues;
3. an otherwise identical proof-distilled descendant with a zero-initialized
   whole-word embedding bridge;
4. an RL continuation of `q-grown-raster-axial-12` as the local-expert control;
5. either `q-grown-raster-invariant-combined-dual-12` or
   `cyclic-graph-dual-v3`, selected after Q154 on exact-common L10 and L1000
   results, complementarity of solved representations, and compute cost.

The three strand-graph descendants start from the same hash-bound terminal
parent state but use distinct registered random seeds. After initialization,
network, optimizer, replay, controller, exposure, trajectory, and outcome state
remain isolated. This makes the seed effect measurable rather than silently
mixing experience across descendants.

## NodeDB proof distillation

Proof supervision is not ordinary one-hot imitation. Every accepted target must
come from a fully replayed route. Currently best observed actions form a set of
positives; worse completed routes may provide comparisons; actions absent from
the graph are unknown and receive no negative gradient. A generated trajectory
counts only after exact replay from its registered starting representation.

The previous bounded-option experiment is a negative integration gate for that
specific loss, not evidence that proof distillation is hopeless. The new test
uses identical parent weights and common evaluation data for the RL-only and
proof-distilled children, which isolates the effect of supervision.

## Whole-word embedding child

The embedding continuation is an external prerequisite. The focused gate must
bind the terminal selected checkpoint, its report, hashes, input-source hashes,
and dimensional contract. Until that binding exists, this child is `QUEUED`.

The first integration is function-preserving: freeze both the strand-graph
parent and embedding encoder, initialize the new residual bridge at zero, and
train only the bridge and calibration layers. The unmodified parent prediction
must be reproduced before any training. Later unfreezing requires a separate
measured gate.

## Promotion measurements

All five lines receive the same registered task order and evaluation accounting.
Promotion is decided on an exact-common representation set using, in order:

- solved count at L10 and L1000;
- crossing changes of replayed witnesses;
- capped iteration means at L10 and L1000;
- unique solved representations contributed beyond the strongest line;
- neural evaluations, optimizer steps, and wall-clock cost;
- retention on the frozen historical set.

No child is promoted from training loss, iteration count, or an unreplayed
witness alone. A witness proves an upper bound; equality with the unknotting
number still requires an independent lower bound.

## Long-word stack

After the focused comparison, the intended long-word system is a shared raster
local expert applied to overlapping windows, a strand-graph global router, and a
whole-word embedding input. The first stack is function-preserving and trains
only routing/calibration. Length grows through 48, 64, 96, and 128 while the
short exact-common benchmark remains in rehearsal. See
`LONG-WORD-HORIZONTAL-STACKING.md` for the detailed design.

## Goal-conditioned extension

The direct-witness model is the first milestone. The next head conditions on a
source node and target node and proposes a replayable transformation minimizing
crossing changes. Equivalent-node pairs provide a special zero-CC curriculum:
the policy must learn isotopy/navigation moves without spending a crossing
change. Exact replay and a hard CC counter remain outside the neural model.

The final objective is a proposal system that can emit its own complete
certificate, while deterministic validation remains the authority that accepts
or rejects it.
